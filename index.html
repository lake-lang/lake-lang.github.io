Lake

A language for lay programmers.

June 2025. I'm actively (20 hours per week) working on a first public alpha version. The purpose of this first alpha version would be to showcase Lake and convince other developers to help build a first beta version.

Lake is designed for lay programmers. That is, non-expert and non-professional programmers. Currently, without Lake, lay programmers must choose between weak languages designed for children (e.g. Scratch) or powerful languages designed to be also used by experts and professionals (e.g. Python and JavaScript). These powerful languages force lay programmers to deal with confusing matters that are not relevant to their limited needs. With Lake I want to offer a language that is less powerful but powerful enough for a lay programmer, such that many confusing matters are completely removed.

Lake is not designed for learning how to program; it is an ergonomic tool for real work. Besides Lake I work on a project with the goal of teaching programming to a general audience (future lay programmers). Part of this project is a series of progressive languages, optimized for learning. The plan is to release Lake at the same time as this educational project, so an absolute beginner can smoothly progress from the educational languages into Lake.

Some more detail:

  • Write and run Lake in a web browser1. This lets you use Lake anywhere. A native client is on the roadmap, but the browser is the primary target.
  • A Lake program always runs in the same order as you read it. The execution model is single-threaded, synchronous and blocking1. No event loop, no concurrency. Instead of throwing exceptions, a program crashes loudly.
  • Lake is tolerant to mistakes. If you accidentally cause an infinite loop, just pause or stop the program without fuss1.
  • To run a Lake program you always only provide a single file of source code. There are no modules, so no module management and no missing or outdated dependencies. Instead of modules you can use the extensive standard library. If you're annoyed that you have to write or copy-paste some useful code often, complain about it on the forum; it might get added the standard library.
  • The runtime comes with a window for drawing and clicking on, keyboard support and spreadsheets. Use the standard library to interact with these systems.
  • Lake offers room to grow. There are beginner lay programmers and experienced lay programmers. As you gain experience you may choose to use more advanced language features. However, a beginner can do everything with basic language features. The examples in the documentation show alternatives for different levels of experience.
1: A runtime in the browser that is blocking and that you can pause/stop at any moment comes with the downside that it is orders of magnitude slower than such a runtime as a native client would be. However, in the spirit of Lake, it is still fast enough.
